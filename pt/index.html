Privacidade por padrão

Seus dados Scrum permanecem no navegador.

O ScrumPulse não exige conta, banco de dados hospedado ou serviço externo. O funcionamento local reduz a configuração e mantém o quadro útil mesmo sem internet.

Foco no facilitador

Um auxílio de trabalho, não outro sistema para administrar.

O quadro foi criado para quem facilita Planning, Daily Scrum, Review e Retrospectiva. Quando necessário, os itens podem apontar para tickets externos, como Jira.

Dúvidas comuns

Perguntas sobre o quadro Scrum gratuito

O ScrumPulse é realmente gratuito?

Sim. O aplicativo web é gratuito e seu código-fonte está disponível sob a licença Apache 2.0.

Precisa criar conta ou configurar banco de dados?

Não. O ScrumPulse funciona no navegador e armazena o workspace localmente. Você pode exportar um backup JSON quando quiser proteger ou transferir os dados.

O ScrumPulse funciona sem internet?

Sim. O aplicativo foi projetado para uso offline e não depende de um backend hospedado durante a execução.

Ele substitui o Jira?

O ScrumPulse é um workspace focado em facilitação e planejamento, não um sistema completo de tickets. Itens do backlog e Sub-tasks podem conter links para ferramentas externas, como Jira.

Para quem o ScrumPulse foi criado?

Ele é especialmente útil para Scrum Masters, Product Owners, Developers, Agile coaches e facilitadores que desejam simplicidade nos eventos e evidências do Sprint.
